# Inquiry pattern

This folder contains `InquiryFilterPanel.tsx`, `InquiryPage.tsx`, and `types.ts`, but the page contract/implementation is currently incomplete and has no representative production module use. Treat it as a scaffold, not an established inquiry framework.

An inquiry should eventually own transient filters and read-only results while the feature owns query contracts. Until completed and tested, compose shared forms/grid/feedback directly in the feature.
