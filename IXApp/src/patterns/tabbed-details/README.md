# Tabbed Details pattern

`TabbedDetailsPage.tsx` and `types.ts` implement a details page whose content is divided into tabs. The feature owns tab definitions/content, selected record, data loading, permissions, and mutations.

Use when one record has several peer detail views. Use FastTabs instead when sections should collapse within a form.
