# Setup pattern

`SetupPage.tsx`, `SetupNavigation.tsx`, and `types.ts` implement navigation among related setup areas. Use for configuration pages grouped by a stable section list, not for a transactional workflow.

The module supplies navigation definitions, content, permissions, forms, and API behavior. The pattern supplies page composition.
