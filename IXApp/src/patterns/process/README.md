# Process pattern

`ProcessNavigation.tsx` and `ProcessStepIndicator.tsx` implement step navigation presentation. `ProcessPage.tsx` and `types.ts` are incomplete, so this is not a complete wizard controller.

Use the navigation components only with feature-owned step state and validation. Do not confuse this generic sequential pattern with the Workflow Process Builder.
