# Communication Module

The Communication module centralizes all outbound and inbound messaging across the IAX platform.

## Key Features
- **Email Delivery**: SMTP integration, email queuing, and delivery tracking.
- **Notifications**: In-app alerts, push notifications, and SMS routing.
- **Templates**: Dynamic message templates with variable substitution and localized content.
- **Audit Logs**: Comprehensive tracking of all communications sent from the system.
