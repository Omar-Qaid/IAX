# Route layouts

`AppLayout.tsx` wraps authenticated pages in `AppShell`; `AuthLayout.tsx` hosts login-style routes; `FullScreenLayout.tsx` supports pages such as Process Builder that need a shell-free work area. Layout selection is performed in the app route configuration, not by feature pages.
