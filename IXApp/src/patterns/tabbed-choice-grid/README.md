# Tabbed Choice Grid

Use `TabbedChoiceGridPage` when top tabs select a functional area, a left single-choice rail selects a category or type, and the right datagrid maintains rules for that choice.

The pattern owns presentation, standard action-pane composition, and tab/choice selection. The feature page owns data loading, validation, CRUD, permissions, dialogs, and lookup behavior.

`InventPostingPage` is the reference implementation.
