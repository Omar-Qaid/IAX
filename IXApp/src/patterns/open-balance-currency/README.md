# Open balance currency

Shared, read-only layout for `CustOpenBalanceCurrency` and `VendOpenBalanceCurrency`, based on the supplied D365 customer-balance screenshot. It uses the existing enterprise ListDetailsPage pattern, EditableViewField and DataGrid. The generic pattern owns Back, list toggle, Customer ribbon, Search, Options, attachments and utility controls. Edit/New/Delete reuse EnterpriseCrudActions in a disabled state because calculated balances are read-only. Search toggles the currency-grid filter row; Open transactions is in the Customer ribbon. The optional shared backCommand callback preserves the existing account-specific return destination. Feature pages own API calls, permissions, company-scoped caching and navigation.

Transaction currency rows stay separate. Accounting and reporting columns use their stored amounts; the page performs no FX conversion. Missing reporting data is unavailable, not zero. Customer credit remaining here is the configured credit limit less the posted open accounting balance. This basic balance inquiry does not calculate sales-order exposure, credit-management rules or forecasts. See Microsoft's [balance-based credit check](https://learn.microsoft.com/en-us/dynamics365/finance/accounts-receivable/configure-customer-invoices).

Names retain `Name` and `NameAlias` and use the shared direction-aware display helper. A related customer/vendor balance is loaded separately only with its transaction-view permission. It uses the explicit `CustTable.VendAccount` link, never a shared name or party inference.

Open transactions now links to the read-only account-scoped inquiry, using the existing typed open-balance endpoint and shared simple-list pattern. Microsoft documents the customer-transactions inquiry in [Customer transactions](https://learn.microsoft.com/en-us/dynamics365/finance/accounts-receivable/customer-transactions-list-page). Details and Aging periods still require their destination screenshots; no settlement editor or aging setup form is inferred from toolbar labels.
