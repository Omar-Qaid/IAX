# Shared services

- `notificationStore.ts` and `notificationService.ts`: shared notification queue and imperative interface.
- `preferenceService.ts`: preference persistence support.
- `storageService.ts`: browser storage wrapper.
- `logisticsAddressMockData.ts`: current in-memory logistics records.

These services are client-side/shared infrastructure, not business API repositories.
