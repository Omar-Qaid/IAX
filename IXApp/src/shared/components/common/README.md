# Common components

Small route-agnostic building blocks: `AppIconButton`, `AppMenu`, `AppTooltip`, `AsyncBoundary`, `ResponsiveStack`, and `VisuallyHidden`. Use them when their accessibility/loading/responsive behavior avoids repeated local composition; keep business meaning out of this folder.
