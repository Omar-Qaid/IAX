# Form components

Contains responsive layout (`FormContainer`, `FormRow`, `FormColumn`, sections/groups), action and validation/error summaries, `EntityForm`, and `useEntityForm`. `FormColumn` defaults to 12/6/4/3 columns across breakpoints.

Feature modules own schemas, values, and persistence. Use React Hook Form/Zod where the implemented feature follows that flow and surface backend validation through summaries/field errors.
