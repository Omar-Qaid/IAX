# Tree Details pattern

**Nothing is implemented here.** The folder previously held `TreeNavigation.tsx`,
`TreeDetailsPage.tsx` and `types.ts` as empty files. An earlier version of this README said
`TreeNavigation.tsx` implemented tree navigation; it was a zero-byte file and has been removed.

For a working searchable tree/detail composition use the implemented **List Details Tree** pattern
instead. Do not adopt this one until selection, loading, empty states, responsive behavior and tests
exist.
