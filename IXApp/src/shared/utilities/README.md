# Shared utilities

Helpers for localized grid columns (`localizeColumns`) and localized record names
(`localizedName`). Unlike `core/utilities`, these helpers may depend on shared UI contracts.

Action filtering, grid operations/export, page behavior and permission helpers are **not** provided
here: those files existed as empty placeholders and were removed. Permission checks go through
`core/permissions`.
