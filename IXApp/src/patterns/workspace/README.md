# Workspace pattern

`WorkspacePage`, `WorkspaceSection`, and `WorkspaceTile` implement an overview composition with typed contracts. Use for navigation/KPI/task entry points rather than entity editing.

The feature provides live values, links, permissions, loading, and error behavior. Tiles are presentation; they do not fetch data themselves.
