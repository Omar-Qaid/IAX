# Application shell

Owns the authenticated frame: `AppShell`, `AppTopBar`, `AppSidebar`, module navigation, company selector, global search, command palette, settings and notification drawers, notification menu, and user menu. Token files centralize shell dimensions and styling values.

Shell components consume app navigation/preferences and auth contexts. Business-specific commands and page forms should remain in modules or patterns.
