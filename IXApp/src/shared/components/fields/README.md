# Shared fields

Provides text, select, boolean, number/currency, date/date-time, enum, bilingual, generated-code, display, and lookup/grid-lookup controls plus defaults and prop contracts.

`AppTextField` can read React Hook Form context; `AppSelectField` requires explicit form control/name for RHF use. Confirm each field's contract instead of assuming identical registration behavior. Business validation remains in the feature schema.
