# Master Form pattern

`MasterFormPage.tsx`, `useMasterFormPage.ts`, and `types.ts` implement a full-record form composition. Use for a single master record with page actions and form sections, not for a list/detail or header/lines transaction.

The feature owns React Hook Form/Zod schema, default values, load/save mutations, permissions, and field composition. The pattern coordinates page/form presentation.
