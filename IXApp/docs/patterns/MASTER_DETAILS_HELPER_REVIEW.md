# Sales-order extra helper review

Scope: the eight sales-order helpers that have no matching responsibility file in free-text invoice. Each file and its callers were inspected. Common document/header/line composition files were compared but not treated as extra helpers. This is a frontend responsibility review; it does not claim backend or external D365 validation.

| Original helper                        | Decision                                                  | Evidence and resulting ownership                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `details/salesOrderDetailsConfig.ts`   | Retain feature mappings; remove dead export               | Header/line master routes and preview entities refer to SalesTable/SalesLine fields and inventory/tax/customer routes. `toAddressPreview` maps the sales delivery-address option shape. Header fields, sections, controller and line fields consume these mappings. Removed `salesOrderRibbonPinnedStorageKey`, which had no callers.                                                                                         |
| `details/useSalesOrderOptions.ts`      | Retain                                                    | Six translated option lists describe sales delivery, sourcing, ATP/CTP, transport and reservation. The document controller and line field/tab builders use them. Invoice does not expose these enums.                                                                                                                                                                                                                         |
| `details/useSalesOrderDocumentData.ts` | Retain                                                    | Composes company-scoped order/header/line/totals/address/copy queries and invalidates order/journal caches. Query keys, endpoints and enabled conditions are sales-specific. The invoice has a different whole-document API. No generic endpoint inference was introduced.                                                                                                                                                    |
| `lines/salesLineDiscount.ts`           | Retain                                                    | Price-unit normalization, amount/percentage synchronization, rounding and multiline discount subtraction are sales pricing rules. Grid and line-detail editors call them. Invoice lines do not carry this discount contract.                                                                                                                                                                                                  |
| `lines/SalesOrderLineState.ts`         | Retain typed state; extract generic action coordination   | Drafts include an order ID and SalesOrderLineRecord baseline; consumers use pending-save refs, saved new-row identity, cell navigation and debounced order totals refresh. These persist across document tabs. Save/Cancel locking and the optional pre-save commit now live in shared `CommitAwareCrudActions`, used by both invoice and sales order. The retained action adapter only maps the sales draft/reset callbacks. |
| `lines/SalesLineValueField.tsx`        | Move to shared; remove sales-only file                    | Buffered decimal text, focus selection and numeric accessibility do not use sales data. Shared `fields/BufferedValueField.tsx` is now used by sales editors and invoice quantity/unit-price editors.                                                                                                                                                                                                                          |
| `lines/SalesLineGridSurface.tsx`       | Move to shared; remove sales-only file                    | Keyboard/mouse navigation, copy/paste and asynchronous commit gating depend only on DataGridHandle and callback props. Shared `data-grid/ExternalCellEditSurface.tsx` retains those behaviors. It is optional for externally controlled cells; invoice's native grid editor already owns its navigation and is not wrapped in a second event controller.                                                                      |
| `lines/SalesLineCell.tsx`              | Replace with shared typed factory; remove sales-only file | The context only stabilizes column definitions while external editor rendering changes. Shared `data-grid/createCellRenderer.tsx` is generic over the row type. Sales creates its renderer once at module scope. Native invoice renderEditCell does not need an external-cell context.                                                                                                                                        |

Invoice-only helpers `details/freeTextInvoiceModel.ts` and `lines/freeTextInvoiceLine.ts` remain necessary: they map record/line IDs, initialize invoice drafts and validate the invoice ledger/description/quantity/price contract. They do not duplicate the sales discount or per-line persistence contract.

## Result

Three sales-only helper files were removed in favor of shared implementations. Generic async action coordination was removed from the sales state file and is now used by both pages. Five sales extra helper files remain, with domain consumers and responsibilities identified above. No compatibility wrappers, features or routes were added.

Validation covers partial numeric input/upstream resets, renderer updates/provider isolation, failed commits, concurrent action locking, generic grid keyboard/mouse/clipboard interactions, sales discounts, and focused sales/invoice page regressions. Live browser appearance and backend behavior are outside this review.
