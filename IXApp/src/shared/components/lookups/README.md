# Lookup subsystem

Provides lookup fields, dialog, grid, filter/search controls, value rendering, types, and `useLookup`. It supports selectable multi-column datasets without embedding business endpoint knowledge.

Features supply lookup rows, columns, identity/value mapping, loading/error state, and remote filtering behavior. Use module lookup configuration for domain-specific choices.
