# Process pattern

**Nothing is implemented here.** The folder previously held `ProcessNavigation.tsx`,
`ProcessStepIndicator.tsx`, `ProcessPage.tsx` and `types.ts` as empty files. An earlier version of this
README said the navigation components were implemented, which was never true of a zero-byte file; the
files were removed rather than left as a trap.

A generic wizard controller needs feature-owned step state and validation. Do not confuse this intended
sequential pattern with the Workflow Process Builder, which is implemented.
