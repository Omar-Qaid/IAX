# Finance Module

The Finance module provides the core financial and accounting capabilities for the IAX platform.

## Key Features
- **General Ledger**: Chart of accounts, journal entries, and financial periods.
- **Currencies & Exchange Rates**: Multi-currency support and historical exchange rate tracking.
- **Taxation**: Tax codes, rates, and calculation engines.
- **Invoicing & Billing**: Accounts receivable, accounts payable, and payment processing.
