# Inquiry pattern

**Nothing is implemented here.** The folder previously held `InquiryFilterPanel.tsx`, `InquiryPage.tsx`
and `types.ts` as empty files; they were removed because an empty module cannot be imported and
suggested a framework that did not exist.

An inquiry should eventually own transient filters and read-only results while the feature owns query
contracts. Until it is built and tested, compose shared forms/grid/feedback directly in the feature.
