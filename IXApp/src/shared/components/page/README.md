# Page components

Defines page container/content/header/title/section/summary/status primitives, enterprise list header, related-information and utility-rail surfaces, and `UnsavedChangesGuard`.

`UnsavedChangesGuard` reflects the existing before-unload behavior; it is not documentation for a complete React Router navigation blocker. Features own record state, actions, and data fetching.
