# Logistics drawers

Exports postal-address and electronic-address drawers, and registers the postal-address record preview (`postalAddressRecordPreview.ts`: Location, Effective, Address), which pages fill with the address data they already hold. They use shared logistics types and `useLogisticsAddress`; current supporting records come from `shared/services/logisticsAddressMockData.ts`.

The components provide editing presentation, not a live logistics backend integration.
