# Feedback states

Standard presentation for loading, empty/no-results, errors, access denial, alerts, notifications, and empty-grid watermarks. Components receive state/message/action props; they do not log errors or fetch data.

Choose `EmptyState` for no data, `NoResultsState` for filters with no matches, and `ErrorState` for recoverable page errors.
