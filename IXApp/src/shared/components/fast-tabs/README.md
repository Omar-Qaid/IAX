# FastTabs

`FastTabs`, `FastTab`, `FastTabHeader`, and `FastTabSummary` implement collapsible form sections with summaries and error indicators. State may be controlled or owned by the component according to the typed contracts.

Use for sections within one page/form, not peer navigation views.
