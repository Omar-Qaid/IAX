# Localization

Initializes i18next, defines supported languages/types, and exposes `useAppTranslation`. Translation resources live under `public/locales/en` and `public/locales/ar`; the application theme changes direction for Arabic.

Add user-facing strings to both locale resources and test direction-sensitive layouts.
