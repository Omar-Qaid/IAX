# Dialogs

Provides `AppDialog`, action layout, confirmation/delete dialogs, `FormDialog`, lookup/process dialogs, `AppHistoryDrawer`, typed contracts, and `useDialog`. Feature code owns submitted data and mutations; dialogs own focus/modal presentation and confirmation interaction.

Use the smallest appropriate surface and expose loading/error state explicitly.
