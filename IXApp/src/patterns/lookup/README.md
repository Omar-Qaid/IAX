# Lookup page pattern

`LookupPage.tsx` and `types.ts` provide a page-level lookup composition. Use it for a dedicated selectable search page; embedded field/dialog lookup experiences are owned by `shared/components/lookups`.

The caller supplies data, columns, selection behavior, and navigation/result handling. API and query ownership remains with the business module.
