# Shared types

Contains the reusable `logistics` contracts. Keep component-only props with their subsystem and
backend DTOs with their module.

Action, form, navigation, page and record contracts are **not** defined here: those files existed as
empty placeholders and were removed. Subsystem contracts currently live with their components, for
example `components/data-grid/types.ts` and `components/lookups/types.ts`.
